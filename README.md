# Tour Life — ATPキャリアシミュレーション (v1.7)

公開ページ: https://hkoby0326.github.io/tour-life/

「試合は観るもの、人生は選ぶもの」。17歳前後の無名選手として、1週＝1ターンで出場大会・練習・休養を選び、ATP No.1を目指すテキスト中心のキャリアシム。実際にプレーする要素はなく、試合はポイント単位の確率モデルで自動生成される。

## v1.7 の追加 — 自動進行の優先順位
- 「自動」はグランドスラム、マスターズ1000、自国のATP大会を最優先する。これらは負荷上限・連戦制限より優先され、疲労が65を超える場合だけ休む
- 翌週にグランドスラム／マスターズがあり、疲労25超・負荷が上限近く・2週連戦のいずれかなら、今週は休養か調整練習にして万全で臨む
- 実測（ジュニア出自4人×8年、トップ100のシーズン）: GS出場 2.6→3.8/4、マスターズ 5.8→8.8/9、自国ATP 0.5→0.9/1。年間出場数は20.6で変わらず（250が減った）
- ホームの「今週の決断」に理由が出る（「グランドスラムを最優先」「来週の全豪オープンに備えて休養」）

## v1.6 の追加 — スポンサータブ
- **カテゴリ**: ラケット／ウエア／シューズは各1社、その他（銀行・ドリンク・保険・航空・時計・車・暗号資産取引所）は2社まで。ブランドはすべて架空（`src/data_sponsors.js`）
- **解放と提示額**: 各ブランドに解放ランキング（400／150／60／15位など）。週給は「契約時のランキング × カテゴリの配分 × ブランドの格」で決まり、契約期間（1〜3年）中は固定。契約金は週給10週分×年数。エージェント雇用で提示額 ×1.2
- **効果**: ラケットはサーブ・ラリー・リターンへの試合中ボーナス、シューズは怪我率と回復、ウエアは回復、その他は移動費・治療費・時差疲労など。上位ブランドほど露出義務（撮影・イベント）があり、勝負所でわずかに不利
- **ボーナス条項**: 優勝／1000優勝／GS優勝で契約ごとに一時金（時計ブランドのGS $500k など）
- **期限と乗り換え**: 満了時に更新イベント（現在のランキングで再提示）。途中解除は残り期間の25%が違約金。暗号資産取引所は年20%で破綻し契約消滅
- **収支との関係**: 従来の自動「ランキング連動スポンサー」は25%に縮小して「小口スポンサー・出場手当」に。大口はすべてタブで結ぶ契約になる。全キャリアは入門ブランド3社の1年契約から始まり、既存セーブにも同じ初期契約を補う。新ブランドが解放されると受信箱に通知
- 収入の実測（自動進行で入門ブランドを更新し続けた場合）はトップ30で年 $290k。上位ブランドに乗り換えると $1.5M 前後まで伸びるので、タブを使うかどうかで差が出る

## v1.5 の追加 — お金の流出と使い道
「上に行くと収入が上がって余裕が出る」への対応。自動進行での計測ではトップ30の年間純益が $3.5M → $1.2M、平均残高が $10.6M → $5.1M になった。
- **流出（A）**: 税＝賞金とスポンサー収入の30%（支援は非課税）。エージェント手数料＝スポンサー収入とアピアランスフィーの15%（エージェント雇用時。契約額 ×1.3 は据え置き）。移動費はトップ100で ×1.4、トップ30で ×2、トップ10で ×2.5（帯同チームの移動・宿泊のグレード）。4,000km超の移動は翌週に疲労 ＋3、8,000km超で ＋6
- **怪我の家計**: 離脱中はランキング連動スポンサーが半額、治療・リハビリ費が毎週 $2k／$5k／$10k（軽傷／中程度／手術）。チーム給与は払い続けるので、トップ選手でも長期離脱中は残高が減る（コーチとスタッフを揃えたトップ30で週 −$20k 前後）
- **使い道（B）**: 財務タブ「資産と投資」。プライベート移動（移動費 ×3、長距離の疲労半減）、専属メディカル契約（年 $300k、怪我 ×0.7、リハビリ費 −50%、離脱 −20%、最高30位で解放）、トレーニング拠点（$1.5M、練習 ＋10%、休養回復 ＋5、最高50位）、アカデミー設立（$3M、毎年母国の新人がアカデミー卒として登場、引退時の総括に加わる、最高20位）
- **投資イベント**: トップ100・残高 $800k 以上で不定期に出資話。残高の30%を1年拘束し、45% で約1.8倍、35% で微増、20% でほぼ損失
- 財務タブの内訳とシーズン別に税・手数料・治療費・契約・投資の行を追加

## v1.4 の追加 — 試合スタッツとキャリアスタッツ
- **試合スタッツ**（観戦画面・結果タブの各試合）: 総ポイント、エース、ダブルフォルト、1stサーブ率、1st／2ndサーブ得点率、サービスゲーム、ブレーク/BP、被BPセーブ、ウィナー、アンフォーストエラー、ネットポイント、タイブレーク、最長ラリー、試合時間（推定）
- **キャリアスタッツ**（選手タブ、通算／今季の切替）: サーブ（エース・DF/試合、1stサーブ率、1st/2nd得点率、サービスゲーム獲得率、BPセーブ率）、リターン（リターンポイント獲得率、BP変換率、リターンゲーム獲得率、総ポイント獲得率、ネットポイント、ウィナー/UE）、勝負所（タイブレーク、最終セット、第1セットを落として逆転／取って逆転負け、MPセーブ、最長連勝）、戦績（対Top10、決勝、サーフェス別、カテゴリ別、平均・最長試合時間、最長ラリー）
- 他選手のスカウティングにも通算スタッツ行（エース/試合、1st得点率、キープ率、BP変換、TB、最終セット、対Top10）。全選手が試合ごとに通算を更新する
- 試合モデルに 1st/2nd サーブとネットプレーの分類を追加（1stサーブ率 ~63%、1st得点率 ~73%、2nd得点率 ~50%、ネットポイント獲得 ~70% を目安に校正）。既存セーブは履歴から通算を再構築（新しい指標はそれ以降の試合から積み上がる）

## v1.3 の追加 — 難易度と成長曲線、観戦アニメーション
- **「100位を超えるとイージー」の是正**: 原因は (1) 人間の隠し天井の床が AI の上位10%相当だったこと、(2) 16〜18歳で年 +6〜8 伸びて20歳で完成していたこと。成長の年齢カーブを 22〜25 歳まで伸びる形に平らにし（16〜19歳は従来の約65%、22〜25歳は据え置き〜やや増）、AI の若手のオフ週練習を強化。自動進行での計測では、トップ100到達が平均で約1シーズン遅れ（ジュニア出自で19〜20歳）、100位→30位は天井80以上なら2〜3シーズン、天井80未満は40〜80位で頭打ち、世代の才能でもトップ10は25〜27歳。天井の分布自体は変えていない（既存セーブとの互換のため）
- **難易度設定**（キャリア作成時に選択。標準＝上記の「緩め」）: やさしい＝成長 ×1.2・収入 ×1.3・怪我 ×0.8・天井 +3・AI若手の成長 ×0.8。難しい＝成長 ×0.85・収入 ×0.8・怪我 ×1.15・天井 −4・AI若手 ×1.2。設定画面に表示
- **観戦アニメーションの刷新**: ポイントを「サーブ → ラリー → 結末」の飛行列として組み立て、requestAnimationFrame で描画。ボールは影つきの放物線で飛び、打つ側にヒットリング、受ける側は落下点へ移動する。ウィナーは相手の逆を突いて抜け、ミスはネット（赤く変色）かアウトに消え、エースは触れずに抜ける。「アニメーションを減らす」設定では最終位置だけ置く

## v1.2 の追加
- **宿敵ストーリー**: 因縁メーター（0〜100、ホームの宿敵カードに表示）。対戦・順位の交差・宿敵のビッグタイトルで上がり、時間と友好的な選択で下がる。専用イベント3種（メディアの因縁特集／オフシーズンの合同練習の誘い／宿敵の長期離脱）、順位を抜いた・抜かれたニュース、宿敵戦では因縁が強いほどクラッチ差が勝負所に効く
- **スカウト精度**: 他選手の能力値は推定値（誤差 ±6）。対戦を重ねると ±4→±2 に縮まり、アナリストを雇うと正確になる。自分の値は常に正確
- **セーブスロット**: 3つのキャリアを並行保存（設定／スタート画面から切り替え・コピー・削除）。殿堂ギャラリーは共通
- **サウンドとモーション（UI-8）**: Web Audio で合成した効果音（ポイント・エース・ブレーク・セット・勝敗・節目のファンファーレ）。既定オフ、観戦画面と設定で切り替え。「アニメーションを減らす」設定と OS の reduce-motion に対応
- **オンボーディング（UI-9）**: 初回キャリア開始時の「遊び方」4ステップ、最初のシーズンだけ各画面上に出るヒントカード（閉じると再表示されない。設定で再表示・常時表示を選べる）
- **差分描画**: モーダルは独立レイヤーで描画し、開閉で背後の画面を再構築しない。同じ画面の再描画ではスクロール位置を保持
- **観戦モードの見切れ修正**: スマホで上部（大会名・ラウンド）が隠れていた問題。`100dvh` と上寄せのシートに変更
- **試合モデルの校正**: 実ツアー平均に合わせてエース／ダブルフォルト率を調整（ハードで1選手あたり約6エース・2.2DF、ホールド率80%、クレー75%、グラス85%、タイブレーク発生 16〜26%）。`tools/calibrate.js` が毎回出力する

## 遊び方
`index.html` をブラウザで開くだけ（サーバー不要、単一ページ＋JS）。セーブはブラウザの localStorage に毎週自動保存。設定タブからJSONのエクスポート／インポート可。

- **出自**を3つから選ぶ: ジュニア王者（16歳）／叩き上げ（18歳）／大学経由（21歳）。ポテンシャル（能力の天井）は非表示。約10%で「世代の才能」。
- **プラン**タブで4週分の行動（大会エントリー／練習（重点2スキル）／休養／おまかせ）をまとめて決めて進める。ダブルス併用、試合プラン（攻撃的・守備的・体力温存）とセット間の切替ルールもここで。「自動進行」は停止条件（自分の大会終了・ランキング節目・怪我・イベント・宿敵戦・シーズン終了）まで「おまかせ」で進める。
- **結果**タブは期間の成長（スキルごとの増減）・週ごとの試合詳細・ニュースをまとめた月間ダイジェスト。
- **観戦モード**: グランドスラム、決勝、1000の準決勝、宿敵戦、トップ10戦、ATPファイナルズはポイント単位で観戦できる（プランタブで条件を選択）。再生速度・1ポイント送り・セット終了まで・スキップ。セット間に試合プランを変えられ、変更はその場の結果に効く（事前計算の再生ではない）。
- **財務**タブで残高の推移、今季の収支内訳（賞金／支援／ランキング連動／契約スポンサー／経費／チーム／移動）、直近12週、シーズン別の台帳を見る。
- **プラン**タブは出られない大会（ランキング不足・格下・低確率WC）を隠し、今季の出場数と直近8週の負荷、目安（トップ20で年15〜20大会、トップ100で22〜26、下部で26〜30）を表示。「おまかせ」はこの目安に沿って休む。
- ランキング表・試合結果・宿敵の名前をクリックすると、その選手のスカウティングレポート（能力・サーフェス・成績・対戦成績）が開く。
- **チーム**タブでコーチ（技術／フィジカル／メンタル／クレー／芝、週給制）とフィジオを雇う。候補はシーズンごとに入れ替わる。
- **イベント**（身体の違和感、デビスカップ招集、スポンサー打診、エキシビション、合宿、日本選手なら「西織の後継者」報道）は選択肢付きで届く。
- **シーズン総括**は年末に自動表示。宿敵（同年代の生成選手）との対戦成績、来季の防衛ポイント、コーチの成長コメント（隠しポテンシャルのヒント）を含む。
- 36歳でキャリア終了。引退時に「どう記憶されたか」のエピローグと殿堂判定。

## 実装内容
| 領域 | 内容 |
|---|---|
| カレンダー | ATPツアー61大会（2026年近似、GS/1000/500/250/Finals）＋週ごとの Challenger・ITF（日本開催も含む） |
| ランキング | 52週ローリング、ベスト19＋Finals、エントリーは6週前のランキングで判定、予選・WC・バイ |
| 試合 | ポイント単位のステッパー（観戦モードはこれをUIから1ポイントずつ進める）。サーブ側ポイント獲得率モデル（サーフェス係数・疲労・クラッチ・モメンタム）。GSは5セット、最終セットは10ポイントTB |
| 成長 | 年齢カーブ×隠しポテンシャル×練習の重点＋試合経験値。30歳以降は身体能力が衰える |
| 疲労・怪我 | 疲労で能力低下＆怪我確率上昇。試合中・練習中の両方で発生し、年齢（30歳以上）で増える。軽傷（1〜2週）／中（3〜8週）／大怪我（10〜22週、身体能力減退）。大会中に負傷すると棄権（W/O）。校正値: 1選手あたり年1.0件、約4週の離脱、10週以上の長期離脱は年12%（`tools/injury_stats.js`） |
| 引退 | 設定タブからいつでも引退可。30歳以降の大怪我で「身体の限界」イベント（続けると怪我しやすく衰えが加速／今季限りで引退）。36歳のシーズン終了で自動引退。AI選手は37歳で強制、34歳で100位外なら6割、31歳で250位外なら6割、29歳で320位外なら5割、27歳以上でランク外なら5割の確率で毎年引退 |
| 資金 | 賞金・支援・ランキング連動スポンサー／基本支出・チーム・移動費。移動費は拠点（連戦中は前の大会地）からの距離（$0.25k/1,000km＋固定$0.75k、2週大会は＋$0.4k）×帯同人数（本人＋コーチ＋帯同スタッフ）。赤字だと2,500km超の移動不可 |
| AI選手 | 初期ロースター130人（実在選手をモデルにした架空名、能力は推定）＋生成200人。同じ成長・衰え・引退モデルで動き、毎年新人が生成される |
| エントリー | トップ50はツアー大会のみ、トップ100はCH50/75に出ない、ITFは200位以下。ATP大会のカットオフは「昨年の実際の当落線」を記憶して予測（上位選手が250を飛ばす分だけ下位に門戸が開く）。各AI選手は週に1大会にコミットする |
| チーム・介入 | コーチ5種×質3段階（上位ほど良い候補が来る）、サポートスタッフ5職（フィジオ／トレーナー／ヒッティング／エージェント／アナリスト。最高ランキングで解放）、試合プラン4種とセット間の自動切替 |
| イベント・ダブルス | 選択肢付きイベント6種、ダブルスは「現地にいる週の副業」として最小実装（賞金・疲労・ネット経験値のみ、ランキングなし） |
| 殿堂 | 引退したキャリアはスタート画面の殿堂ギャラリーに残る |
| 決定性 | シード付き乱数。リロードしてやり直しても同じ結果（アイアンマン） |

## GitHub Pages で公開する
`.github/workflows/pages.yml` がリポジトリをそのまま GitHub Pages に配信する。リポジトリの Settings → Pages → Source を「GitHub Actions」にし、`main` に push すると公開される（private リポジトリは有料プランが必要。public なら無料）。

## コーチ契約
週給は質で大きく違う（★1 約$0.9k、★2 約$2.5k、★3 約$6.5k、±20%）。候補は1〜3年契約。途中解除は残り期間の半額（上限26週）が違約金。相性は雇って8週で判明し、練習効果に ±20% 前後効く。満了時は更新交渉（契約中にランキングが上がっていれば25%増額）。
