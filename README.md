# Tour Life — ATPキャリアシミュレーション (v2.11)

公開ページ: https://hkoby0326.github.io/tour-life/ （公開用リポジトリ: https://github.com/hkoby0326/tour-life 。このディレクトリが開発元で、リリース時に同期する）

「試合は観るもの、人生は選ぶもの」。17歳前後の無名選手として、1週＝1ターンで出場大会・練習・休養を選び、ATP No.1を目指すテキスト中心のキャリアシム。実際にプレーする要素はなく、試合はポイント単位の確率モデルで自動生成される。

## v2.11 の追加 — ゴール（レガシー・シーズン目標）と後半の盛り上げ
- **レガシー（キャリア評価点）**: 全選手共通の配点で実績を1つの数字に（GS 100、ファイナルズ 50、マスターズ1000 30、500 15、250 8、チャレンジャー 1、No.1在位 3/週、年末トップ10 10/回、年末No.1 40/回）。上部バーと「ホーム」に常時表示。最終目標は**殿堂ライン 250**（キャリアを引退まで回したシミュで約12%が到達。GS優勝は約17%なので、GS1勝だけでは届かない）。殿堂入りの判定もこのラインに統一
- **この世界の歴代ランキング**と**記録への挑戦**: GS優勝・マスターズ優勝・ツアー優勝・No.1在位・年末トップ10の最多記録（保持者つき）と自分の差。歴代20位以内での浮上、殿堂ライン到達、最多記録の更新で通知。ゲーム開始以降の成績で数える（開始時のベテランの過去の実績は含まない）
- **シーズン目標**: 毎年3つ（年末ランキング／タイトル／GS、ランク外の時期は年間勝利数）を実力に合わせて自動設定。達成で成長ポイント（ランキング目標 +3、他 +2）、3つとも達成でスポンサーボーナス。タイトル・GS・勝利数は達成した瞬間に、ランキングは年末に判定。シミュでの達成数は 3つ 16%／2つ 29%／1つ 42%／0 13%
- **衰えとの向き合い方（30歳〜）**: 30歳の開幕に「30歳の岐路」イベント。選んだ後も選手タブ・ホームで変えられる
  - 身体を守る: 練習配分のフィジカル1コマにつき身体の衰え −10%（最大 −50%）
  - スタイルを変える: 育成スタイル「ベテランの技巧」（29歳〜）。確立でサーブ +2.5・勝負所 +8、技術の衰え −50%
  - 出場を絞る: 方針「厳選（ベテラン）」（30歳〜）。GS・マスターズ・500中心、大きな大会でサーブ・リターン +1.5、怪我 ×0.75、身体の衰え −15%
  - 選手タブに来季の衰えの見込み（対策なしとの比較）を表示
  - 30歳時点から5年間の比較（8キャリア）: 平均順位は 何もしない 64位、身体を守る 56位、スタイル転換 55位、出場を絞る 74位（※大会照準の効果を足す前の数値。絞る方はポイントが減るぶん順位は下がりやすい）

## v2.6 の追加 — 特性の5段階とスロット
- **問題**: 成長ポイントは年 3〜9（トップ10で約9）貯まり、15種の特性が各3〜6ptだったので、キャリアの途中でほぼ全部取れて余っていた
- **5段階**: 各特性に Lv1〜5。強化コストは 2→4→6→9→12pt（最大まで計33pt）、効果は Lv1 の ×1.6／2.1／2.5／2.8。互角の相手への勝率で、ビッグサーブ Lv1 +3.6% → Lv5 +7.5%、立ち上がり +2.6% → +8.5%、赤土の申し子（クレー）+4.4% → +13%。コート外の特性（頑丈な身体・回復力・吸収力）もレベルで効果が上がる
- **スロット**: 同時に持てるのは3つ（最高20位で+1、最高3位で+1、最大5）。外すと使ったポイントの半分が戻る
- **上位レベルの条件**: 能力条件のある特性はレベルごとに +3（例: ビッグサーブ Lv5 はサーブ84以上）。条件のない特性は Lv4 に最高50位以内、Lv5 に最高10位以内
- 1キャリアの獲得（約50〜90pt）では「2つを極める」か「4つを Lv3 前後まで」の選択になる
- 既存セーブで習得済みの特性は Lv1 として引き継ぐ（スロット数を超えていても外されない）
- 逆転の鬼・先行逃げ切りはレベルを上げても伸びが弱かったので基本値を上げた

## v2.4 の追加 — 能力値とランキングの乖離
- **総合の式を試合エンジンに合わせた（根本原因）**: 旧式はフォア・バックを重く数え、集中力を含んでいなかった。エンジンの実際の重み（サーブ 18%、リターン 16%、スピード 15%、パワー 12%、フォア 10%、バック 8%、集中 8%、クラッチ 5%、ネット 4%、スタミナ 4%）に変更。旧来の育成（サーブ5・ストローク5、総合の重みに沿ったコーチ任せ）は「総合は高いが試合で勝てない」偏った選手を作っていた。素のエンジンで総合が同じ相手との勝率は 48〜49% になり、総合と強さが一致した
- **練習配分の初期値を均等型に**: サーブ3・ストローク3・リターン3・フィジカル1。既存セーブで初期値のまま触っていない配分も移行する。コーチ任せの底上げも新しい重みで選ぶ
- **「実力」を追加**: 総合にサーフェス適性（年間の開催比率で加重）、試合勘、人間の場合はスタイル・特性・用具・メンタルコーチを足した試合での強さ。ランキング表・スカウティング・選手タブに表示（他選手はスカウティングの推定）
- **サーフェス適性の伸びを人間とAIで同じに**（試合ごと +0.18。従来は人間 +0.25、AI +0.15 の隠れた不公平）
- **スタイル確立ボーナスを特性1つ分に**: 旧値（サーブ +1 など）は勝率 +0.4% 程度で、選ぶ意味がほぼなかった。サーブ +5.5／ラリー +3.5／リターン +5.5／全体 +1.6／クレーでラリー +5／勝負所 +16 にして、互角の相手への勝率がそれぞれ約 +3.5%（クレー巧者はクレーで +6%）
- **自動進行の大会選びをポイント効率型に**: 80位より下では、ATP の予選（負けると0点）よりチャレンジャーの本戦を優先。マスターズの予選は90位以内、自国 ATP の予選は150位以内に限定（GS の予選は250位以内で継続）。1シーズンの獲得ポイントは同じ実力帯で 565→744
- **難易度は据え置き**: 自動進行が効率的になった分、人間の成長補正を ×1.15→×1.08 に下げ、標準でのトップ100到達（中央値約4年）と最高順位（中央値約15位）を v2.2 と同等に保った
- 観戦画面でダブルフォルトのときにまれに止まる不具合（v1.3 から）を修正

## v2.3 の追加 — 資金難の扱い
- **段階的な結果**: 残高マイナスで 2,500km 超の遠征不可（従来どおり）とコーチ・スタッフの新規雇用不可。$50k の赤字で給与を2週払えないとコーチとスタッフが離脱。$150k の赤字で年1回「キャリアの危機」（銀行から借りる／家族に頼る／節約モード／引退）
- **資金繰り**（財務タブ）: 家族からの借金（一度・$40k・無利子）、協会の強化費（年1回・25歳まで・ランキングと協会規模で $4〜38k）、クラウドファンディング（一度・600位以内・$15〜40k）、銀行ローン（$100k・週0.15%・上限 $250k）、欧州クラブリーグ（8週・週 $2〜4k・試合勘 +4/週・疲労 +6/週・練習 ×0.8）、レッスンのアルバイト（8週・週 $1.2k・練習 ×0.6・試合勘 −2/週）。借入は賞金とスポンサー収入の25%で自動返済
- **節約モード**: 単独遠征で移動費 ×0.6。大会中はコーチ・帯同スタッフの効果なし、大会週の疲労 +3、時差疲労 ×1.5
- **気づかせる仕組み**: 残高が $10k を切ると年1回「資金が尽きかけている」イベント。ホームにも警告と財務タブへのリンク
- **治療費をランキング連動に**: 下位選手が手術で週 $10k を払い続けて −$270k まで沈むケースがあったため、50位以内 ×1、200位以内 ×0.4、それより下 ×0.2
- 実測（各8人・3シーズン）: 日本の叩き上げは変更前 8/8 人が平均 106 週マイナス・最低 −$348k。節約モードだけだと平均 44 週の浅い赤字（欧州に行けない）が残り、強化費・家族・クラファンを併用すると 0 週。米国と大学出身はほぼ影響なし

## v2.0 の追加 — 練習配分と特性
- **練習配分**（選手タブ「育成計画」）: 重点スキル2つの選択を、週10コマの時間配分に置き換えた。サーブ（サーブ・パワー）／ストローク（フォア・バック・ネット）／リターン・守備（リターン・スピード）／フィジカル（スタミナ・スピード・パワー・耐久。4コマ以上で疲労が溜まる）／メンタル（クラッチ・集中）／実戦形式（全体を少しずつ。1コマごとに試合勘 +1.5・疲労 +0.5）。「コーチに任せる」では目標スタイルに沿って毎週組み直す。既存セーブは従来の重点2つから配分を作る
- **特性**: タイトル（下部 1／250・500 2〜3／1000 4／GS・ファイナルズ 6）、トップ200以上の節目（2）、シーズン終了（1）で成長ポイントが貯まり、15種の特性を習得できる。試合の特定の場面だけに効く（ブレークポイントでのサーブ、タイブレーク、逆転、最終セット、クレー、大舞台、ホーム、格上相手など）ものと、コート外（怪我 ×0.8、回復 +4、練習 ×1.1）のもの。一部は能力条件つき
- 特性は乱数を消費しない補正なので、観戦しても飛ばしても結果は同じ。互角の相手への勝率は特性1つで +2〜7 ポイント（場面限定のものほど大きい）
- 実測（ジュニア 10 シード、4 シーズン）: 成長ポイントは平均 11〜14（年 3 前後）。既定配分（サーブ5・ストローク5）は従来の重点2つと同等の成長。フィジカル5は疲労と試合勘の低下で順位が下がる

## v1.8 の追加 — 試合勘・自信、自動進行の方針

## v1.6 の追加 — スポンサータブ

## v1.5 の追加 — お金の流出と使い道
「上に行くと収入が上がって余裕が出る」への対応。自動進行での計測ではトップ30の年間純益が $3.5M → $1.2M、平均残高が $10.6M → $5.1M になった。
- **流出（A）**: 税＝賞金とスポンサー収入の30%（支援は非課税）。エージェント手数料＝スポンサー収入とアピアランスフィーの15%（エージェント雇用時。契約額 ×1.3 は据え置き）。移動費はトップ100で ×1.4、トップ30で ×2、トップ10で ×2.5（帯同チームの移動・宿泊のグレード）。4,000km超の移動は翌週に疲労 ＋3、8,000km超で ＋6
- **怪我の家計**: 離脱中はランキング連動スポンサーが半額、治療・リハビリ費が毎週 $2k／$5k／$10k（軽傷／中程度／手術）。チーム給与は払い続けるので、トップ選手でも長期離脱中は残高が減る（コーチとスタッフを揃えたトップ30で週 −$20k 前後）
- **使い道（B）**: 財務タブ「資産と投資」。プライベート移動（移動費 ×3、長距離の疲労半減）、専属メディカル契約（年 $300k、怪我 ×0.7、リハビリ費 −50%、離脱 −20%、最高30位で解放）、トレーニング拠点（$1.5M、練習 ＋10%、休養回復 ＋5、最高50位）、アカデミー設立（$3M、毎年母国の新人がアカデミー卒として登場、引退時の総括に加わる、最高20位）
- **投資イベント**: トップ100・残高 $800k 以上で不定期に出資話。残高の30%を1年拘束し、45% で約1.8倍、35% で微増、20% でほぼ損失

## v1.3 の追加 — 難易度と成長曲線、観戦アニメーション
- **「100位を超えるとイージー」の是正**: 原因は (1) 人間の隠し天井の床が AI の上位10%相当だったこと、(2) 16〜18歳で年 +6〜8 伸びて20歳で完成していたこと。成長の年齢カーブを 22〜25 歳まで伸びる形に平らにし（16〜19歳は従来の約65%、22〜25歳は据え置き〜やや増）、AI の若手のオフ週練習を強化。自動進行での計測では、トップ100到達が平均で約1シーズン遅れ（ジュニア出自で19〜20歳）、100位→30位は天井80以上なら2〜3シーズン、天井80未満は40〜80位で頭打ち、世代の才能でもトップ10は25〜27歳。天井の分布自体は変えていない（既存セーブとの互換のため）
- **難易度設定**（キャリア作成時に選択。標準＝上記の「緩め」）: やさしい＝成長 ×1.2・収入 ×1.3・怪我 ×0.8・天井 +3・AI若手の成長 ×0.8。難しい＝成長 ×0.85・収入 ×0.8・怪我 ×1.15・天井 −4・AI若手 ×1.2。設定画面に表示
- **観戦アニメーションの刷新**: ポイントを「サーブ → ラリー → 結末」の飛行列として組み立て、requestAnimationFrame で描画。ボールは影つきの放物線で飛び、打つ側にヒットリング、受ける側は落下点へ移動する。ウィナーは相手の逆を突いて抜け、ミスはネット（赤く変色）かアウトに消え、エースは触れずに抜ける。「アニメーションを減らす」設定では最終位置だけ置く

## 遊び方
`index.html` をブラウザで開くだけ（サーバー不要、単一ページ＋JS）。セーブはブラウザの localStorage に毎週自動保存。設定タブからJSONのエクスポート／インポート可。

- **出自**を3つから選ぶ: ジュニア王者（16歳）／叩き上げ（18歳）／大学経由（21歳）。ポテンシャル（能力の天井）は非表示。約10%で「世代の才能」。
- **プラン**タブで4週分の行動（大会エントリー／練習（重点2スキル）／休養／おまかせ）をまとめて決めて進める。ダブルス併用、試合プラン（攻撃的・守備的・体力温存）とセット間の切替ルールもここで。「自動進行」は停止条件（自分の大会終了・ランキング節目・怪我・イベント・宿敵戦・シーズン終了）まで「おまかせ」で進める。
- **結果**タブは期間の成長（スキルごとの増減）・週ごとの試合詳細・ニュースをまとめた月間ダイジェスト。
- **観戦モード**: グランドスラム、決勝、1000の準決勝、宿敵戦、トップ10戦、ATPファイナルズはポイント単位で観戦できる（プランタブで条件を選択）。再生速度・1ポイント送り・セット終了まで・スキップ。セット間に試合プランを変えられ、変更はその場の結果に効く（事前計算の再生ではない）。
- **財務**タブで残高の推移、今季の収支内訳（賞金／支援／ランキング連動／契約スポンサー／経費／チーム／移動）、直近12週、シーズン別の台帳を見る。
- **プラン**タブは出られない大会（ランキング不足・格下・低確率WC）を隠し、今季の出場数と直近8週の負荷、目安（トップ20で年15〜20大会、トップ100で22〜26、下部で26〜30）を表示。「おまかせ」はこの目安に沿って休む。
- ランキング表・試合結果・宿敵の名前をクリックすると、その選手のスカウティングレポート（能力・サーフェス・成績・対戦成績）が開く。
- **チーム**タブでコーチ（技術／フィジカル／メンタル／クレー／芝、週給制）とフィジオを雇う。候補はシーズンごとに入れ替わる。
- **イベント**（身体の違和感、デビスカップ招集、スポンサー打診、エキシビション、合宿、日本選手なら「西織の後継者」報道）は選択肢付きで届く。
- **シーズン総括**は年末に自動表示。宿敵（同年代の生成選手）との対戦成績、来季の防衛ポイント、コーチの成長コメント（隠しポテンシャルのヒント）を含む。
- 引退は自分で決める（任意・来季限り表明）か、年齢とランキングの条件で強制。引退時に「どう記憶されたか」のエピローグと殿堂判定。

| 成長 | 年齢カーブ×隠しポテンシャル×練習の重点＋試合経験値。30歳以降は身体能力が衰える |
| 疲労・怪我 | 疲労で能力低下＆怪我確率上昇。試合中・練習中の両方で発生し、年齢（30歳以上）で増える。軽傷（1〜2週）／中（3〜8週）／大怪我（10〜22週、身体能力減退）。大会中に負傷すると棄権（W/O）。校正値: 1選手あたり年1.0件、約4週の離脱、10週以上の長期離脱は年12%（`tools/injury_stats.js`） |
| 引退 | 設定タブからいつでも引退可。30歳以降の大怪我で「身体の限界」イベント（続けると怪我しやすく衰えが加速／今季限りで引退）。シーズン終了時に34歳以上で250位外、または38歳以上で100位外なら強制引退（年齢だけでは引退しない）。32歳以降に1年で順位が倍以上かつ40位以上落ちる、または最高100位以内だった選手が200位外に落ちると「引退を考える」イベント（続ける＝自信 +3／来季限りで引退＝ラストシーズンは勝負所 +2）。AI選手は37歳以上ならトップ30外で引退・トップ30内でも35%、34歳で100位外なら6割、31歳で250位外なら6割、29歳で320位外なら5割、27歳以上でランク外なら5割の確率で毎年引退 |
| 資金 | 賞金・支援・ランキング連動スポンサー／基本支出・チーム・移動費。移動費は拠点（連戦中は前の大会地）からの距離（$0.25k/1,000km＋固定$0.75k、2週大会は＋$0.4k）×帯同人数（本人＋コーチ＋帯同スタッフ）。赤字だと2,500km超の移動不可 |
| AI選手 | 初期ロースター130人（実在選手をモデルにした架空名、能力は推定）＋生成200人。同じ成長・衰え・引退モデルで動き、毎年新人が生成される |
| エントリー | トップ50はツアー大会のみ、トップ100はCH50/75に出ない、ITFは200位以下。ATP大会のカットオフは「昨年の実際の当落線」を記憶して予測（上位選手が250を飛ばす分だけ下位に門戸が開く）。各AI選手は週に1大会にコミットする |

| イベント・ダブルス | 選択肢付きイベント6種、ダブルスは「現地にいる週の副業」として最小実装（賞金・疲労・ネット経験値のみ、ランキングなし） |

## GitHub Pages で公開する
`.github/workflows/pages.yml` が `tourlife/` を GitHub Pages に配信する。リポジトリの Settings → Pages → Source を「GitHub Actions」にし、`main` に push すると公開される（private リポジトリは有料プランが必要。public なら無料）。

## コーチ契約
週給は質で大きく違う（★1 約$0.9k、★2 約$2.5k、★3 約$6.5k、±20%）。候補は1〜3年契約。途中解除は残り期間の半額（上限26週）が違約金。相性は雇って8週で判明し、練習効果に ±20% 前後効く。満了時は更新交渉（契約中にランキングが上がっていれば25%増額）。

## 既知の制限
- ダブルスのランキング、オリンピックは未実装
- 登場選手はすべて架空（2025/26年のツアーをモデルにした近似名）。能力値・年齢は推定値
- ポイント表はATPルールの近似（バイ後の初戦敗退など主要な例外は実装済み）
